🔧 Sistema de Gestión de Ferretería


Trabajo Práctico Integrador – Programación 1


📋 Descripción del proyecto

Sistema de gestión de inventario desarrollado en Python para una ferretería. Permite administrar las herramientas y controlar las cantidades disponibles mediante un menú interactivo por consola.



⚙️ Funcionalidades

Cargar herramientas al inventario.

Mostrar el inventario completo.

Consultar el stock de una herramienta.

Generar un reporte de herramientas agotadas.

Dar de alta nuevos productos.

Actualizar el stock mediante ventas e ingresos.



🛠️ Tecnologías utilizadas

Python 3.14

Visual Studio Code 1.145.1



📁 Estructura del proyecto

main.py: archivo principal desde el cual se inicia el programa.

funciones.py: contiene las funciones que permiten realizar las distintas operaciones del sistema.
